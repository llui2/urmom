\title{Frequency-dependent fitness reshapes evolutionary accessibility on genotype space}
\maketitle

\section{Idea}

A genotype does not need to have one fixed fitness value. Its fitness can depend on which other genotypes are currently present in the population.

We study this in the simplest possible setting. Genotypes are binary sequences. Mutation connects sequences that differ by one bit. Each genotype has an intrinsic fitness, but the current population adds a second, frequency-dependent contribution to fitness.

The main question is:

\begin{quote}
How does frequency-dependent fitness coupling change which mutational paths are accessible?
\end{quote}

This is not mainly a coexistence problem, and the matrix below should not be read as a generic ecological interaction matrix. It is a \emph{fitness-coupling matrix}: it tells us how the frequency of one genotype changes the fitness of another.

\section{Model}

Let
\[
x_i\in\{0,1\}^L,
\qquad
i=1,\ldots,N,
\qquad
N=2^L,
\]
be the genotypes, and let $p_i$ be their population frequencies,
\[
p_i\geq 0,
\qquad
\sum_i p_i=1.
\]

Mutation follows the geometry of the hypercube. We use
\[
Q_{ii}=1-\mu,
\qquad
Q_{ij}=\frac{\mu}{L}
\quad\text{if}\quad
d_H(x_i,x_j)=1,
\]
and $Q_{ij}=0$ otherwise.

Each genotype has an intrinsic fitness $g_i$. The effective fitness is
\begin{equation}
f_i(\mathbf p)
=
g_i
+
\beta
\sum_j A_{ij}p_j.
\label{eq:fitness}
\end{equation}

The matrix $A$ is the key object. Its entry $A_{ij}$ means:

\begin{quote}
how the frequency of genotype $j$ changes the fitness of genotype $i$.
\end{quote}

Selection acts through
\begin{equation}
\widetilde p_i
=
\frac{
p_i \exp\!\left(\eta f_i(\mathbf p)\right)
}{
\sum_k p_k \exp\!\left(\eta f_k(\mathbf p)\right)
},
\label{eq:selection}
\end{equation}
followed by mutation,
\begin{equation}
p_i(t+1)
=
\sum_j
\widetilde p_j Q_{ji}.
\label{eq:mutation}
\end{equation}

So the model contains three separate objects:
\[
\boxed{
\mathbf g
\quad\text{intrinsic fitness},
\qquad
A
\quad\text{frequency-dependent fitness coupling},
\qquad
Q
\quad\text{mutation geometry}.
}
\]

\section{What the matrix changes}

Selection only depends on fitness differences. Between genotypes $i$ and $k$,
\begin{equation}
f_i-f_k
=
g_i-g_k
+
\beta
\sum_j
(A_{ij}-A_{kj})p_j.
\label{eq:relative-fitness}
\end{equation}

The first term is the difference in the underlying fitness landscape. The second term depends on the current population.

This means that the sign of selection can change while the intrinsic landscape stays fixed.

Consider a population concentrated at genotype $i$. A one-step mutant $j$ appears through $Q$. Its initial selective advantage is
\begin{equation}
s_{j|i}
=
g_j-g_i
+
\beta
\left(
A_{ji}-A_{ii}
\right).
\label{eq:invasion}
\end{equation}

Without frequency-dependent coupling, the mutant is unfavorable when
\[
g_j-g_i<0.
\]

With coupling, the same mutant can become favorable when
\[
g_j-g_i
+
\beta(A_{ji}-A_{ii})
>0.
\]

The matrix $A$ does not create the mutation. The mutation operator $Q$ does that. The role of $A$ is to change what selection does with the mutant after it appears.

\begin{quote}
Mutation determines which moves are possible. Intrinsic fitness gives their baseline value. Population-dependent fitness coupling can change which of those moves are favored.
\end{quote}

\section{Evolutionary accessibility}

For a fixed intrinsic landscape, define a directed edge
\[
i\longrightarrow j
\]
when $d_H(x_i,x_j)=1$ and the mutant $j$ can initially invade the resident $i$.

Without coupling,
\[
i\longrightarrow j
\qquad\Longleftrightarrow\qquad
g_j-g_i>0.
\]

With coupling,
\[
i\longrightarrow j
\qquad\Longleftrightarrow\qquad
g_j-g_i+\beta(A_{ji}-A_{ii})>0.
\]

The accessibility graph therefore depends on the fitness-coupling structure.

The basic problem is to understand when increasing $\beta$, changing the structure of $A$, or changing the ruggedness of $\mathbf g$ opens or closes evolutionary routes.

Examples of questions are:
\begin{itemize}
\item Can a population escape a local fitness peak that traps it when $\beta=0$?
\item When does a previously accessible path disappear?
\item Can frequency dependence create persistent polymorphism instead of a single path?
\item Which simple properties of $A$ control these changes?
\end{itemize}

\section{Why this is not just a Lotka--Volterra interaction matrix}

A generalized Lotka--Volterra model usually evolves absolute abundances and writes interactions directly in the per-capita growth rates.

Here the state is a frequency vector on a fixed genotype space, mutation explicitly connects nearby genotypes, and $A$ is used only to modify relative fitness before mutation and selection.

There is also a simple redundancy. If
\[
A'
=
A+\mathbf 1\mathbf v^{\mathsf T},
\]
then every genotype receives the same extra fitness
\[
\mathbf v^{\mathsf T}\mathbf p.
\]
This cancels from relative selection. Therefore only differences between rows of $A$ affect the dynamics.

The relevant object is not every entry of $A$ separately, but how $A$ changes relative fitness on the simplex.

\section{First setup}

The first version should stay small and transparent.

\begin{enumerate}
\item Use binary genotype space with nearest-neighbor mutation.
\item Choose a rugged intrinsic fitness landscape with a clear local peak and a higher peak elsewhere.
\item Start the population near the local peak.
\item Prescribe a simple low-dimensional family of fitness-coupling matrices $A$.
\item Vary the coupling strength $\beta$.
\item Measure which mutational edges become accessible and whether the population escapes the local peak.
\end{enumerate}

The first pass should not optimize entropy or learn a completely free $N\times N$ matrix. The earlier entropy objective naturally pushed the system toward a nearly uniform diversity-preserving solution. Here diversity is an output, not the target.

A useful simple family is to make coupling depend on Hamming distance,
\[
A_{ij}
=
a_{d_H(x_i,x_j)}.
\]
This respects the same genotype geometry as mutation and is analytically tractable. More structured or asymmetric coupling can be introduced later if directional rerouting is needed.

\section{Mathematical direction}

When $A$ depends only on Hamming distance, both mutation and fitness coupling respect the symmetry of the hypercube. They can then be decomposed into the same Walsh modes.

This gives two complementary descriptions of the same system:
\begin{enumerate}
\item a local accessibility picture, where interactions open and close mutational edges;
\item a spectral picture, where mutation damps genotype-space modes and fitness coupling changes their growth or decay rates.
\end{enumerate}

The first concrete goal is therefore not to find the best matrix $A$. It is to determine which simple forms of frequency-dependent fitness coupling qualitatively change evolutionary accessibility.
